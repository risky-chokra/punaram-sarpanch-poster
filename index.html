☁ Google Drive से बैकग्राउंड चुनें

लिंक paste करें, OAuth से उस folder को browse करें, फिर image चुनते ही पोस्टर अपडेट होगा।

Drive Picker तैयार हो रहा है…

Google Cloud के एक ही project में Drive API और Google Picker API चालू करें; उसी project का Web OAuth Client ID, API key और numeric Project Number यहाँ भरें। OAuth JavaScript origin ठीक https://risky-chokra.github.io रखें; Testing mode में अपना Google account Test users में जोड़ें। API key website restrictions में https://risky-chokra.github.io/* और Picker iframe के लिए https://docs.google.com/* जोड़ें; API restrictions केवल Google Picker API + Google Drive API रखें। लिंक से nested folders browse कर सकते हैं; ऐप केवल चुनी image के लिए drive.file scope लेता है। Client ID/API key/Project Number public identifiers हैं—client secret या access token यहाँ न डालें।
